ℹ️ About J6 Format

  • 6-character wallet identifier
  • Used in legacy AGT systems
  • Example: J6A3B9
  • Limited address space

ℹ️ About J8 Format

  • 8-character wallet identifier
  • Extended version of J6
  • Example: J8C7D2E5
  • Larger address space

ℹ️ About AGT Format

  • Modern AGT wallet standard
  • Starts with "agt1qzxk" prefix
  • Example: agt1qzxkqacaccde60jt8d9f
  • Enhanced security features
